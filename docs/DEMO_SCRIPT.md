# HushHour 90-Second Demo Script

## 0:00-0:08 Hook

"On any campus, at any moment, thousands of students feel lonely. Most won’t book counseling in that moment. But they will tap one button."

## 0:08-0:18 The Tap (Live)

Two devices side-by-side:

- Device A taps **I want to talk**
- Device B taps **I want to talk**

"This is live. Not seeded. They’re matching in real time."

## 0:18-0:35 The Match

Both enter chat quickly.

"They don’t know each other’s identity, and they never will. They have five minutes, then this dissolves."

Send one message from each side.

## 0:35-0:55 Safety Moat Demo

Type on one side:  
`DM me on instagram @demoaccount`

Show moderation redaction on recipient side.

"Every message is moderated before delivery. Contact info is redacted immediately."

Then type a rehearsed concerning phrase that triggers crisis flag.

"If language indicates crisis, we pause and route to trained support."

## 0:55-1:15 Crisis Path

Return home, tap **I’m in crisis right now**.

"This path never peer-matches. It routes directly to 988, Crisis Text Line, Trevor Project, and campus counseling. AI is backstop, not primary care."

## 1:15-1:25 Aftercare + Pulse

Show aftercare:

- feeling check-in
- resources
- listener CTA

Show Pulse:

"Campus-wide aggregate only. No private conversations exposed."

## 1:25-1:30 Close

"HushHour. Five minutes. One stranger. Nobody alone tonight."

## Demo Logistics Checklist

- Keep 3 devices pre-authenticated
- Verify venue Wi-Fi and fallback hotspot
- Have a backup screen recording
- Keep one test account in crisis route for quick access
